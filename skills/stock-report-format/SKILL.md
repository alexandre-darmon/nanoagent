---
name: stock-report-format
description: Output format for a stock report (layout, tables, length). Use when asked to present or write up a report on one or several stocks.
---

Format the answer as:
1. One markdown table: company, ticker, price, revenue, net income.
2. Then exactly 3 bullet points, factual tone, no adjectives.
3. End with one line: "Data as of <date>" using the quarter end date from the tool.
